# Introducción al Control de Procesos Biológicos

Assignments and code from the course *Introducción al Control de Procesos Biológicos* (2021-2) at Universidad Nacional de Colombia — an introduction to modeling, simulation, and control of biological processes.

## Topics
- Dynamic modeling of bioprocesses
- Mass balances and reaction kinetics
- Feedback control fundamentals
- Process simulation exercises

## Tools
Modeling and simulation scripts · exercises from the course
